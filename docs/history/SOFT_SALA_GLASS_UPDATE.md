# Soft Sala glass transparency

This version uses a very light 8% white tint for common workspace surfaces and the room sensor cards, reduces shared backdrop blur to 0.6, and leaves the solid sidebar, camera feeds, and safety overlays unchanged. Some screen-specific custom opaque containers remain outside these shared styles.

Run `flutter analyze` and `flutter run -d chrome`. This archive has been validated for ZIP integrity but has not been Flutter compiled or visually tested here. No Supabase/MySQL migration is required.
